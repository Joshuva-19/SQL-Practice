# 💻 SQL Practice

This repository contains my hands-on SQL practice completed as part of my Data Analytics learning journey using MySQL (XAMPP).

## 📌 Repository Objective

The purpose of this repository is to strengthen SQL skills by solving practical data analysis problems using an ecommerce sales dataset.

## 🛠️ Tools Used

- MySQL
- XAMPP
- phpMyAdmin

## 📂 Dataset Information

- Dataset: Ecommerce Sales
- Records: 5,000 (sample dataset)
- Format: CSV

> **Note:** This repository uses a representative sample dataset of **5,000 records** for SQL practice. The original Excel analytics project was developed using a much larger dataset containing **14,500+ records**.

## 📚 SQL Topics Covered

- SELECT
- WHERE
- ORDER BY
- DISTINCT
- LIMIT
- Aggregate Functions
- GROUP BY
- HAVING
- JOINS
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- CASE Statements
